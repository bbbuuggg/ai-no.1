# 原型代码规范（宽松）

原型是一次性代码，用于验证想法。规范**故意宽松**以最大化迭代速度。目标是学习，不是生产质量。

## 原型中**允许**

- 硬编码值（无需数据驱动配置）
- 极少或无文档注释
- 简单架构（无需依赖注入）
- 单例与全局状态
- 复制粘贴代码（无需抽象）
- 调试输出留在原处
- 占位美术与音频
- Quick-and-dirty 方案

## 原型中**仍然必需**

- 每个原型独立子目录：`prototypes/[name]/`
- 每个原型**必须**有 `README.md` 包含：
  - 被测假设
  - 如何运行原型
  - 当前状态（进行中 / 已结束）
  - 发现（原型结束后更新）
- 生产代码**禁止**引用或导入 `prototypes/`
- 原型**禁止**修改 `prototypes/` 之外的文件
- 原型**禁止**部署或发布

## Godot 4.6 特定

- 原型场景可直接放 `prototypes/[name]/*.tscn`
- 脚本头必须加标记：
```gdscript
# PROTOTYPE - NOT FOR PRODUCTION
# Question: [被测问题]
# Date: [日期]
```

## 原型成功之后

原型验证了概念且特性进入生产：
1. 原型代码**不**直接迁移——按生产规范重写
2. 原型 `README.md` 发现指导生产设计文档
3. 原型目录保留作参考但不再扩展

## 清理

结论记录后应归档或删除。**禁止**让原型代码通过增量"清理"演化成生产代码。
