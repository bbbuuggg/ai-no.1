# GDD 机制重构：暗出对决 + 陷阱系统 + 认知探针

> 版本：v0.3 | 日期：2026-05-06
> 本文档覆盖 02-symmetric-duel-revision.md 的回合结构、约束令系统，并新增碰撞结算和认知探针机制
> 状态：**已定案，进入实现阶段**

---

## 设计哲学转变

```
v0.2（旧）：玩家打牌 → Boss执行意图 → 约束令是debuff技能牌
v0.3（新）：每回合 = 一局微型心理战（暗出+碰撞+陷阱+认知对抗）
```

核心体验从"计算最优出牌"变为"**预判对手 + 被对手预判**"。
玩家在每个回合中做出的不是数学题，而是心理学题。

## 1. 回合结构（完全重写）

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 回合开始（Round Start）                                   │
│    • 双方抽牌（默认3张）                                     │
│    • 双方获得能量（默认3点）                                  │
│    • 约束陷阱衰减/移除                                       │
│    • Boss公布本回合"认知探针"预判                             │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. 部署阶段（Deploy Phase）—— 仅玩家操作                     │
│    • 可选：部署约束陷阱/空白牌到槽位（消耗约束资源）         │
│    • 可选：消耗1约束资源"干扰"Boss猜测（本回合猜测无效）     │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. 暗出阶段（Blind Phase）—— 双方同时                        │
│    • 玩家选择N张牌面朝下并排列顺序（总能量消耗≤当前能量）    │
│    • 0费牌可免费绑定到任意一张牌（不占能量额度）             │
│    • Boss由AI选择M张牌面朝下排列                              │
│    • 双方确认后锁定（不可更改）                              │
│    • 双方可见对方出牌张数（牌背），不可见内容                 │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. 对决阶段（Clash Phase）—— 逐张翻开                        │
│    • 第1对：玩家翻#1 ↔ Boss翻#1 → 碰撞结算                  │
│    • 第2对：玩家翻#2 ↔ Boss翻#2 → 碰撞结算                  │
│    • ...                                                     │
│    • 多余牌（某方出牌更多）：逐张翻开，按原效果100%直接生效   │
│    • 0费绑定牌随主牌一起翻开，效果叠加到主牌结算中           │
│    • 若Boss翻出的牌匹配陷阱槽位 → 陷阱翻开，追加结算         │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ 5. 认知结算（Probe Phase）                                    │
│    • 统计玩家本回合暗出牌的类型分布                           │
│    • 判定Boss"认知探针"是否猜对                               │
│    • 根据累计/连续命中 → 触发洞察效果                         │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ 6. 回合结束（Round End）                                      │
│    • 手牌上限检查（超7张强制弃）                              │
│    • 持续效果/buff/debuff结算                                 │
│    • 未使用能量清零                                          │
│    • 胜负检查                                                │
│    • 回合计数+1                                              │
└─────────────────────────────────────────────────────────────┘
```

### 关键规则

- **暗出即全部**：没有暗出之后的"自由出牌阶段"，本回合行动全部在暗出阶段决定
- **能量回合清零**：未使用能量不保留至下回合
- **暗出张数公开**：双方可见对方出了几张牌（牌背），但不可见牌面内容

## 2. 碰撞结算系统（Clash Resolution）

### 2.1 三角克制关系

```
        攻击
       ╱    ╲
    克制      被克
     ╱          ╲
  技能 ◄──克制── 防御
```

**攻击 克制 技能 克制 防御 克制 攻击**

- 克制方：效果 **×1.5**（向上取整）
- 被克制方：效果 **×0.5**（向上取整）

### 2.2 完整结算表

| 玩家牌类型 | Boss牌类型 | 玩家效果 | Boss效果 |
|-----------|-----------|---------|---------|
| 攻击 | 技能 | ×1.5 | ×0.5 |
| 技能 | 防御 | ×1.5 | ×0.5 |
| 防御 | 攻击 | ×1.5 | ×0.5 |
| 技能 | 攻击 | ×0.5 | ×1.5 |
| 防御 | 技能 | ×0.5 | ×1.5 |
| 攻击 | 防御 | ×0.5 | ×1.5 |
| 同类型 | 同类型 | ×1.0 | ×1.0 |
| 有牌 | 无对手(多余) | ×1.0 | — |
| 无对手(多余) | 有牌 | — | ×1.0 |

### 2.3 效果倍率的数值处理

| 效果类型 | ×1.5 处理 | ×0.5 处理 |
|----------|-----------|-----------|
| 数值类（伤害/护甲/回复） | 数值×1.5 向上取整 | 数值×0.5 向上取整 |
| 抽牌类（抽N张） | 张数×1.5 向上取整 | 张数×0.5 向上取整（最低1） |
| 状态类（持续N回合） | 回合数×1.5 向上取整 | 回合数×0.5 向上取整（≤0则失效） |
| 能量修正类（±N能量） | 数值×1.5 向上取整 | 数值×0.5 向上取整 |
| 标记/触发类（蓄力等） | 正常生效 | **失效**（持续<1回合） |

### 2.4 数值示例

**示例1：玩家攻击 vs Boss技能**
> 数据脉冲(攻击/5伤) vs 蓄力协议(技能/标记蓄力1回合)
> → 攻击克技能
> → 玩家：5×1.5 = **8伤害**
> → Boss：1回合×0.5 = 0.5 向上取整=1 → 但蓄力是标记类，×0.5视为**失效**

**示例2：玩家防御 vs Boss攻击**
> 防火墙(防御/5甲) vs 回响脉冲(攻击/5伤)
> → 防御克攻击
> → 玩家：5×1.5 = **8护甲**
> → Boss：5×0.5 = **3伤害**（被8甲完全吸收）

**示例3：同类型碰撞**
> 过载冲击(攻击/12伤) vs 双重打击(攻击/5×2)
> → 同类型，双方×1.0
> → 玩家对Boss造成12伤，Boss对玩家造成10伤

**示例4：多余牌**
> 玩家出3张，Boss出2张 → 前2对正常碰撞，玩家第3张按100%效果直接生效

### 2.5 0费绑定牌规则

- 0费牌不独立参与碰撞，**绑定到一张主牌上**
- 翻开时与主牌同时揭示，效果叠加到该对碰撞中
- 克制倍率**同时应用于主牌和绑定牌**
- 一张主牌最多绑定 **1张** 0费牌

**示例**：
> 数据脉冲(1费/5伤) + 绑定残余电弧(0费/3伤) vs Boss技能牌
> → 攻击克技能，倍率×1.5
> → 总伤害 = (5+3)×1.5 = **12伤害**

## 3. 约束陷阱系统（Constraint Trap）

### 3.1 基本规则

| 规则 | 说明 |
|------|------|
| 部署时机 | 回合开始后的"部署阶段"（暗出之前） |
| 槽位数量 | 3个：`攻击触发槽` / `技能触发槽` / `高费触发槽(≥2能量)` |
| 触发条件 | Boss在对决阶段翻出的牌**匹配对应槽位类型**时触发 |
| Boss可见信息 | 可见**哪个槽位被占了**，不可见具体内容（真/空白） |
| 部署消耗 | 真陷阱消耗约束资源（各牌不同），空白牌消耗0 |

### 3.2 陷阱触发流程

```
Boss翻开一张牌
    │
    ▼
检查该牌类型是否匹配某个被占槽位
    │
    ├─ 不匹配 → 正常碰撞结算
    │
    └─ 匹配 → 翻开陷阱
           │
           ├─ 真陷阱 → 陷阱效果生效（可能打断/削弱该牌）
           │           然后再做碰撞结算（陷阱效果优先）
           │
           └─ 空白牌 → 无事发生，正常碰撞结算
                       Boss获知"这个是虚张声势"
```

### 3.3 陷阱牌表（初始）

| 名称 | 英文ID | 触发槽 | 约束资源代价 | 效果 |
|------|--------|--------|-------------|------|
| 中断协议 | `trap_interrupt` | 任意 | 2 | 触发时：该牌**完全无效化**（不生效也不参与碰撞） |
| 能量虹吸 | `trap_siphon` | 任意 | 2 | 触发时：该牌正常结算，但Boss下回合能量-1 |
| 反射棱镜 | `trap_reflect` | 攻击触发 | 3 | 触发时：该攻击牌的伤害**反弹给Boss自己** |
| 类型封锁 | `trap_typelock` | 任意 | 3 | 触发时：该类型牌本场战斗剩余回合内能量+1（永久） |
| 虚影协议 | `trap_bluff_a` | 任意 | 0 | 空白牌。占位无效果 |
| 虚影协议 | `trap_bluff_b` | 任意 | 0 | 空白牌。占位无效果 |

### 3.4 陷阱策略空间

| 玩家选择 | 风险 | 收益 |
|----------|------|------|
| 真陷阱放对位 | 消耗约束资源 | 打断Boss关键牌，巨大节奏优势 |
| 真陷阱放错位 | 约束资源浪费（Boss没出匹配牌） | 无 |
| 空白牌放位 | 无消耗 | Boss可能因看到槽位被占而改变出牌策略 |
| 不部署 | 无 | Boss无顾忌，自由出牌 |

### 3.5 Boss应对逻辑

Boss看到槽位被占时的AI决策：

```gdscript
# 伪代码
var risk_tolerance: float  # 0.0~1.0，按Boss性格设定

func decide_with_traps(occupied_slots: Array) -> Array:
    for card in hand:
        if card_matches_occupied_slot(card, occupied_slots):
            var bluff_probability = estimate_bluff_chance()  # 基于历史空白率
            if randf() < risk_tolerance * bluff_probability:
                # 冒险：赌是空白，照常出
                continue
            else:
                # 规避：换其他类型的牌
                deprioritize(card)
    return sorted_action_sequence
```

## 4. 认知探针系统（Cognitive Probe）

### 4.1 叙事定位

Boss在试图"读懂"玩家的模式。每回合它做一次预判——如果连续猜对，说明它已经掌握了你的思路，将入侵你的系统。

### 4.2 基本规则

| 规则 | 说明 |
|------|------|
| 触发时机 | 回合开始时Boss公布预判 |
| 猜测对象 | 玩家本回合暗出牌中**数量最多的类型**（攻击/防御/技能） |
| 判定时机 | 对决阶段结束后统计 |
| 平局处理 | 如果两种类型并列最多，Boss猜中其中任一即算对 |

### 4.3 猜测算法（Boss侧）

```gdscript
func predict_player_type() -> String:
    # 基于玩家历史出牌统计 + Boss性格权重
    var history_weight := analyze_player_history()  # 过去N回合的类型比例
    var personality_bias := boss_personality.prediction_bias  # 性格偏向
    
    var scores := {
        "attack": history_weight.attack * 0.7 + personality_bias.attack * 0.3,
        "defense": history_weight.defense * 0.7 + personality_bias.defense * 0.3,
        "skill": history_weight.skill * 0.7 + personality_bias.skill * 0.3,
    }
    
    # 加入随机扰动（防止100%可预测）
    for key in scores:
        scores[key] += randf_range(-0.1, 0.1)
    
    return scores.max_key()
```

### 4.4 洞察层级与效果

| 条件 | 效果 | 叙事 |
|------|------|------|
| 猜对1次 | 获得1层"洞察"标记（纯标记，无即时效果） | "它在观察你..." |
| **连续**猜对2次 | **窥视**：随机揭示玩家1张手牌（对Boss可见直到被打出或弃置） | "它看穿了你的一张底牌" |
| **连续**猜对3次 | **干扰**：随机1张玩家手牌下回合不可使用（标记"被锁定"） | "它入侵了你的系统" |
| **累计**猜对5次（整场） | **夺取**：随机1张玩家手牌被永久移除，加入Boss牌库 | "它吞噬了你的代码" |
| 猜错 | 连续计数归零（累计不归零） | "你的变化让它困惑了" |

### 4.5 玩家对策

| 策略 | 操作 | 效果 |
|------|------|------|
| 刻意混乱 | 看到Boss猜"攻击"→ 改为防御/技能为主 | 让Boss猜错，重置连续计数 |
| 消耗干扰 | 部署阶段花1约束资源"干扰探针" | 本回合Boss猜测直接判定为"猜错" |
| 利用窥视 | Boss窥视了你的某张牌 → 故意不打出/最后打出 | 误导Boss后续决策 |
| 接受代价 | 不管猜测，集中精力做最优出牌 | 承受窥视/干扰风险换取更强碰撞结果 |

### 4.6 平衡分析

| 指标 | 数值 |
|------|------|
| Boss基础猜中率 | ~33%（三选一随机） |
| 考虑历史分析后猜中率 | ~45-55%（如果玩家不刻意变化） |
| 玩家刻意应对后猜中率 | ~25-30% |
| 连续2次概率（不应对） | ~25% |
| 连续3次概率（不应对） | ~12% |
| 累计5次（8回合战，不应对） | ~40%概率 |
| 累计5次（8回合战，主动应对） | <5%概率 |

**结论**：正常游玩时"窥视"会偶尔触发（增加紧张感），"夺取"需要玩家完全忽视才会触发（惩罚性机制）。

## 5. 暗出阶段详细规则

### 5.1 出牌约束

- 出牌总能量消耗 ≤ 当前可用能量
- 0费牌不计入能量消耗，但必须绑定到一张主牌上（每张主牌最多绑1张0费）
- 可以选择**不出牌**（出0张），相当于本回合放弃行动（极少见，可能用于欺骗猜测）
- 最少出牌：0张；最多出牌：受能量和手牌数双重限制

### 5.2 排列顺序

玩家选好牌后，**手动排列顺序**（第1位到第N位）。这决定了每张牌与Boss哪张牌碰撞。

**策略指导**：
- 把防御牌排前面 → 预判Boss第一张是攻击（克制它）
- 把攻击牌排前面 → 预判Boss第一张是技能（克制它）
- 把最强牌排最后 → 赌Boss出牌少于你（多余牌100%生效）

### 5.3 Boss暗出AI逻辑

```gdscript
func boss_blind_select() -> Array[CardData]:
    var selected: Array[CardData] = []
    var remaining_energy := current_energy
    
    # 1. 评估场面决定攻防倾向
    var stance := evaluate_stance()  # aggressive / defensive / balanced
    
    # 2. 考虑陷阱槽位情况
    var trap_awareness := assess_traps()  # 哪些槽位被占
    
    # 3. 选牌（优先级+随机）
    var candidates := get_playable_cards(remaining_energy)
    candidates = filter_by_trap_risk(candidates, trap_awareness)
    candidates = sort_by_stance_preference(candidates, stance)
    
    # 4. 贪心选取直到能量耗尽
    for card in candidates:
        if card.energy_cost <= remaining_energy:
            selected.append(card)
            remaining_energy -= card.energy_cost
    
    # 5. 排列顺序（性格决定）
    selected = arrange_by_personality(selected)
    
    return selected

func arrange_by_personality(cards: Array) -> Array:
    match boss_personality.clash_style:
        "aggressive":
            # 攻击牌排前面（试图克制玩家技能）
            return sort_attack_first(cards)
        "defensive":
            # 防御牌排前面（安全优先）
            return sort_defense_first(cards)
        "unpredictable":
            # 随机排列
            cards.shuffle()
            return cards
```

## 6. 对现有牌表的影响与调整

### 6.1 牌值重估

新碰撞系统下，牌的"实际价值"不再固定，取决于碰撞对手：

| 情况 | 实际效率 |
|------|---------|
| 克制对手 | 基础值×1.5 |
| 被对手克制 | 基础值×0.5 |
| 同类/多余 | 基础值×1.0 |

**结论**：单卡数值可以适当下调（因为平均有33%概率获得1.5倍收益）

### 6.2 新增约束令牌池

在原有约束令基础上新增：

| 类别 | 新增牌 | 数量 |
|------|--------|------|
| 陷阱型 | 中断协议、能量虹吸、反射棱镜、类型封锁 | 各1 |
| 空白牌 | 虚影协议 | 2 |
| 消耗型 | 认知干扰（使本回合猜测无效） | 不占牌位，约束资源直接消耗 |

### 6.3 新增Boss专属牌（后续设计）

| 名称 | 类型 | 效果 | 设计意图 |
|------|------|------|----------|
| 深层扫描·改 | 技能 | 揭示1个陷阱槽位是否为空白 | Boss反制虚张声势 |
| 认知聚焦 | 技能 | 本回合猜测命中额外+1层洞察 | 加速认知压力 |
| 模式锁定 | 协议 | 若上回合猜对，本回合所有牌+2伤害/+2护甲 | 奖励连续猜中 |

### 6.4 0费牌新定位

0费牌在新系统中变为"**绑定增幅牌**"：
- 不独立参与碰撞
- 绑定到主牌上，叠加效果
- 共享主牌的克制倍率
- 战略价值：用0费牌垫高关键碰撞的数值

| 旧回合结构（玩家→Boss顺序） | **完全替换**为暗出对决 |
| 旧约束令（限牌/限资源/幻觉） | **限牌/限资源类**转化为陷阱效果；**幻觉类**保留概念融入认知探针 |
| Boss意图预告 | **移除**（暗出系统中Boss意图不再公开） |
| 碰撞结算 | **全新系统** |
| 认知探针 | **全新系统** |
| CardData Resource结构 | 需新增字段：`can_bind_zero_cost`、`trap_slot_type` |
| BattleManager | **完全重写** |
| UI | 暗出选牌/排列、陷阱槽位、认知探针面板 → **全新UI** |
