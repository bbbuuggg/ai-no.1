## 0. 一句话设计

> **每回合 BP 出 4 张牌：火/水/木 3-cycle 克制 + 2 光 2 暗 平衡协同 ×2.0 倍率。**

## 1. 战斗循环（与 GDD-04 BP 对齐，无变化）

```
Round N:
  ① 部署阶段（DEPLOY）     玩家布置陷阱 / 干扰探针
  ② 暗出阶段（BLIND）      双方各选 4 张牌排 4 槽位（含元素+光暗）
  ③ 对决阶段（CLASH）      逐对翻牌结算克制 + 平衡倍率 + 陷阱
  ④ 认知阶段（PROBE）      Boss 命中宣告 + 洞察入队
  ⑤ 回合结束（ROUND_END）  抽牌补满至 4 张 + 应用 pending insights
```

**唯一改动点**：第 ③ 步的克制判定从「ATK/DEF/SKL 三角」改为「火/水/木 3-cycle」，并新增「2:2 平衡协同」检查。

## 2. 火水木 3-cycle 克制（取代旧 ATK/DEF/SKL 三角）

### 2.1 克制环

```
        火 ───克───▶ 木
        ▲             │
        │             克
        克            │
        │             ▼
        └────克──── 水
```

| 关系 | 文字描述 | 设计意义 |
|---|---|---|
| 🔥 **火 克 木** | 烈焰焚林 | 攻击牌克技能/治疗牌 |
| 🌿 **木 克 水** | 草木破石 | 技能牌克防御/护盾 |
| 💧 **水 克 火** | 水能灭火 | 防御牌克攻击 |
| ⚪ 同元素 | 中立平局 | 倍率 1.0 |

**数学性质**：3-cycle 是石头剪刀布的纳什最优解 —— **每个元素都有 1 个克与 1 个被克**，无中立位 → 玩家必须选择。

### 2.2 倍率规则

| 情况 | 玩家方倍率 | Boss 方倍率 |
|---|---|---|
| 玩家克制 Boss | **×1.5**（基础）/ **×2.0**（触发 2:2 平衡）| ×0.5 |
| Boss 克制玩家 | ×0.5 | ×1.5 |
| 同元素 / 中立 | ×1.0 | ×1.0 |

倍率应用对象：`damage` / `armor` / `draw_cards` / `heal` 等所有数值字段，向上取整（`ceili`）。

### 2.3 兼容性

旧牌（未设置 element 字段，`Element.NONE`）会**自动退回 ATK/DEF/SKL 三角克制**（`_legacy_type_counter`），保证 reward_cards 等遗留模块仍可工作。

## 3. 光明 / 暗黑 极性（正交第二维度）

### 3.1 设计哲学

光暗**不是第二个克制环**，而是**正交协同维度**——单张牌出场时光暗不影响伤害，**只有 4 张牌排成"2 光 2 暗"时**才触发集体加成。

| 维度 | 单张计算 | 4 张组合 |
|---|---|---|
| 元素（火水木）| 决定单对克制（×0.5 / ×1.0 / ×1.5）| 无 |
| 光暗 | 不参与单对计算 | **2:2 平衡 → 玩家克制倍率 1.5 → 2.0** |

### 3.2 协同奖励（A2 保底版，仅实装 2:2 平衡）

| 4 张光暗分布 | A2 是否实装 | 效果 |
|---|---|---|
| **2 光 2 暗 ☯ 平衡** | ✅ **唯一实装** | 本回合**所有玩家克制对**倍率 1.5 → **2.0** |
| 4 光 / 4 暗 / 3:1 / 1:3 | ❌ 不实装 | 留作 v0.7.0+ 扩展 |

**关键设计点**：
- 仅放大**正向克制倍率**（1.5 → 2.0），**不**放大被克倍率（×0.5 不变）—— 平衡型玩家不会因平衡而被反惩罚
- **仅奖励玩家方**，Boss 的 2:2 不触发（A2 保底版避免 Boss 强度失控）
- 平衡奖励是**全局**的：4 张牌中只要有任意一对玩家克制，全部吃 2.0 倍率

### 3.3 玩家心智模型

```
我手上有 6 张光 + 4 张暗，本回合该出哪 4 张？
├─ 想拼平衡 ×2.0：选 2 光 2 暗，再挑元素克制
├─ 没办法平衡：选 3 光 1 暗（弱奖励 v0.7.0+）或纯凑能量
└─ Boss 显然要出火 → 我至少塞 1 张水
```

**目标极清晰**："我能不能凑出 2 光 2 暗？" 是新手第 1 局就能问出口的问题。

## 6. 数值平衡公式

### 6.1 单张牌强度评估（v0.5.0 A2 标准沿用）

```
strength = (damage * 1.0) + (armor * 0.8) + (heal * 0.7) + (draw * 3.0) + (ignore_armor ? 2 : 0)
理想强度 / 费用比 ≈ 4.0 ~ 5.5（1 费 4-5 / 2 费 8-10）
```

抽样校验：
- **阳焰** (1 费 / 4 伤+治 2) = 4+1.4 = 5.4 ✓
- **业火** (2 费 / 9 伤) = 9 ÷ 2 = 4.5 ✓
- **荆棘** (2 费 / 7+破甲) = 7+2 ÷ 2 = 4.5 ✓
- **回声盾** (1 费 / 8 甲) = 8×0.8 = 6.4（Boss 强 1 档，预期）

### 6.2 平衡倍率经济学

玩家拼 2:2 平衡需付出：**牌选择灵活度↓** + **能量集中度↑**。
回报：**克制对全部从 1.5 升至 2.0** = +33% 输出。

预期：玩家**每 3 回合能凑 1 次平衡**（10 张牌洗牌 + 4 张手牌），即 ~33% 频率，**不会过强**。
