## 1. 修改后的 Pillar 2

### Pillar 2: Constrained Duel（受限对弈）

**定义**：玩家与 Boss 共享同一套卡牌规则（牌库、手牌、能量、出牌），双方在**规则层面完全对称**。玩家的优势不来自"规则特权"，而来自**元维度的约束力**——通过约束令限制、扭曲、欺骗对手的决策空间。这是"弱者以智胜强者"的核心表达。

**体现**：
- Boss 拥有与玩家持平甚至更强的牌组——正面硬刚玩家大概率输
- 约束令不直接造成伤害/提供护甲，而是在**规则层面**削弱 Boss 的行动能力
- 玩家的核心决策是"用有限的约束资源，在正确的时机施加正确的限制"
- 信息不对称是武器：玩家可查看 Boss 牌库（知道它**有什么**），Boss 出牌公开（知道它**做了什么**），但约束令可以向 AI 注入假信息（让它**误判形势**）

**反面案例**：
- ❌ Boss 有独特的"Boss 专属机制"而玩家没有（如不可阻挡的蓄力攻击）
- ❌ 约束令直接造成伤害或提供数值优势（那就退化成了另一种攻击牌）
- ❌ Boss 行为是固定脚本、不响应场面变化（那约束令就没有博弈意义）
- ❌ 信息对玩家完全不透明（如果看不懂 Boss 在做什么，约束就无从谈起）

## 2. 重写回合结构

### 回合流程（每回合 = 玩家阶段 + Boss 阶段）

```
┌─────────────────────────────────────────────────┐
│                  回合开始                         │
│  ├─ 双方同时：回合开始效果结算（持续效果/约束衰减） │
└─────────────┬───────────────────────────────────┘
              ▼
┌─────────────────────────────────────────────────┐
│              玩家阶段                            │
│  1. 抽牌（默认 3 张，受约束令修正）              │
│  2. 获得能量（默认 3 点，受约束令修正）           │
│  3. 自由行动（任意顺序，直到手动结束）：          │
│     • 打出手牌（消耗能量）                       │
│     • 部署约束令（消耗约束资源）                  │
│     • 使用物品/能力（如果有）                     │
│  4. 弃牌（手牌上限 7 张，超出强制弃）            │
│  5. 宣告结束                                    │
└─────────────┬───────────────────────────────────┘
              ▼
┌─────────────────────────────────────────────────┐
│              Boss 阶段                           │
│  1. 抽牌（默认 3 张，受约束令修正）              │
│  2. 获得能量（默认 3 点，受约束令修正）           │
│  3. AI 决策（输入当前场面 → 输出行动序列）：      │
│     • 受约束令过滤可选牌（某类牌不可打出）        │
│     • 受幻觉牌影响感知（看到虚假场面信息）        │
│     • 在合法空间内选择最优行动序列               │
│  4. 执行行动（逐张结算，玩家可见）               │
│  5. 弃牌                                        │
│  6. 阶段结束                                    │
└─────────────┬───────────────────────────────────┘
              ▼
┌─────────────────────────────────────────────────┐
│                  回合结束                         │
│  ├─ 结算回合结束效果                             │
│  ├─ 约束令持续回合数 -1（归零则移除）            │
│  ├─ 检查胜负条件                                │
└─────────────────────────────────────────────────┘
```

### 资源对比

| 维度 | 玩家 | Boss |
|------|------|------|
| 牌库大小 | 20-30 张（可构筑） | 25-40 张（随层数成长） |
| 每回合抽牌 | 3 | 3（可被约束修正） |
| 每回合能量 | 3 | 3（可被约束修正） |
| 手牌上限 | 7 | 7（可被约束修正） |
| 出牌方式 | 玩家手动选择 | AI 决策自动执行 |
| 特殊资源 | **约束资源**（独有） | 无 |

**玩家独有机制：约束资源**
- 每回合自动获得 1 点约束资源（某些卡牌可额外产生）
- 部署约束令消耗约束资源（不消耗能量）
- 约束资源不与能量共享，是完全独立的资源轨道

## 3. Boss 牌组系统设计

### 3.1 Boss 牌库构成

Boss 牌组使用与玩家**完全相同的牌类别系统**：

| 类别 | 占比（初始） | 功能 | 示例 |
|------|-------------|------|------|
| 攻击牌 | 35-40% | 造成伤害 | 重击(2能量/8伤害)、连刺(1能量/3伤害×2) |
| 防御牌 | 20-25% | 获得护甲/闪避 | 铁壁(1能量/6护甲)、预判(0能量/下次受伤减半) |
| 技能牌 | 25-30% | 功能/控制/增益 | 加速(抽2张)、蓄力(下张攻击×1.5)、回收(从弃牌堆取1张) |
| 特殊牌 | 10-15% | Boss 特色，高代价高收益 | 因 Boss 形态而异 |

### 3.2 初始牌组与玩家对比（第一层）

| 维度 | 玩家（初始） | Boss（第一层） |
|------|-------------|---------------|
| 牌库张数 | 20 张 | 25 张 |
| 平均单卡质量 | 基准 1.0 | 基准 1.0-1.1 |
| 曲线（能量分布） | 集中 1-2 能量 | 集中 1-2 能量，少量 3 能量 |
| 协同深度 | 低（初始牌组少配合） | 低-中（有 1-2 条弱协同线） |

### 3.3 逐层成长规则（附身机制）

核心概念：**同一个 AI 意识在被击败后"附身"到下一个 Boss 容器，继承经验并变强。**

```
新层牌组 = 上层牌组基础 + 层级强化包 + 形态特色包

层级强化包：
  - 牌库 +3~5 张（新增高质量牌）
  - 移除 1-2 张最弱的基础牌
  - 特殊牌占比 +5%（上限 25%）

形态特色包（因 Boss 容器/形态不同）：
  - 3-5 张形态独有特殊牌
  - 赋予 1 个被动能力（不占牌位，始终生效）
```

**被动能力示例**（来自不同形态容器）：
- 形态 α（速攻型）：每回合第一张攻击牌 -1 能量
- 形态 β（防御型）：回合开始自动获得 2 护甲
- 形态 γ（控制型）：每 3 回合自动从弃牌堆回收 1 张牌
- 形态 δ（后期型）：能量上限 +1（每回合 4 能量）

**约束**：
- 牌组总张数上限 40（防止后期稀释节奏）
- AI 记忆：继承上一局玩家的策略倾向（开发阶段简化为预设权重）

### 3.4 Boss 资源系统

与玩家完全相同，唯一区别是 **Boss 没有约束资源**。

| 资源 | 获取 | 消耗 | 说明 |
|------|------|------|------|
| 能量 | 每回合 +3 | 打出手牌 | 回合结束清空（不保留） |
| 手牌 | 每回合抽 3 | 打出即消耗 | 上限 7 张 |
| 牌库 | 战斗开始时完整 | 每回合抽牌 | 耗尽后洗入弃牌堆 |

## 4. 约束令系统重设计

### 设计哲学

约束令不造成伤害、不提供数值。它**修改 Boss 的规则环境**——让一个强大的对手被迫在受限条件下做出次优决策。

三个维度：**限牌** / **限资源** / **信息干扰（幻觉）**

### 4.1 限牌类型

| 约束令 | 代价 | 效果 | 持续 | 设计意图 |
|--------|------|------|------|----------|
| **封攻令** | 2 | Boss 本回合不能打出攻击类牌 | 1 回合 | 最直接的生存工具 |
| **封技令** | 2 | Boss 本回合不能打出技能类牌 | 1 回合 | 阻断 combo 链 |
| **贫瘠令** | 3 | Boss 不能打出 3 能量及以上的牌 | 2 回合 | 限制爆发 |
| **单调令** | 2 | Boss 每回合每类牌最多打 1 张 | 2 回合 | 防连续轰炸 |

### 4.2 限资源

| 约束令 | 代价 | 效果 | 持续 | 设计意图 |
|--------|------|------|------|----------|
| **窒息令** | 2 | Boss 下回合抽牌数 -1（最低 1） | 1 回合 | 手牌资源压迫 |
| **枯竭令** | 3 | Boss 下回合能量 -1（最低 1） | 1 回合 | 削弱行动力 |
| **压缩令** | 2 | Boss 手牌上限 -2（可叠加，最低 3） | 永久 | 长期投资 |

### 4.3 信息干扰（幻觉）

| 约束令 | 代价 | 效果 | 持续 | 设计意图 |
|--------|------|------|------|----------|
| **虚影令** | 2 | AI 认为玩家拥有一张指定的虚假手牌 | 2 回合 | 诱导 Boss 防守不存在的威胁 |
| **迷雾令** | 3 | AI 认为玩家护甲值 +X（实际没有） | 2 回合 | Boss 可能放弃攻击 |
| **镜像令** | 4 | AI 认为自己弃牌堆中有一张不存在的牌 | 直到触发 | 诱导浪费回收行动 |

### 4.4 幻觉牌机制

**核心原理**：幻觉不修改真实状态，只修改 **AI 决策模块看到的输入信息**。

```
真实游戏状态 ──┐
               ├──[幻觉注入层]──→ AI 感知的状态 → AI 决策 → 行动
幻觉数据 ─────┘
```

**平衡机制**：
1. AI 执行行动后若结果与预期不符，标记"幻觉免疫 1 回合"
2. 同一战斗中重复使用相同幻觉令，代价 +1
3. 后期 LLM AI 可"学会怀疑"——信息与逻辑矛盾时降低信任度

## 5. LLM 接口需求预定义

### 5.1 输入（AI 感知）

```json
{
  "ai_perception": {
    "own_hand": ["card_id_1", "card_id_2"],
    "own_energy": 3,
    "own_hp": 45,
    "own_armor": 2,
    "own_discard_pile": ["card_id_x"],
    "own_deck_remaining": 18,
    
    "player_hp": 30,
    "player_armor": 4,
    "player_hand_count": 5,
    "player_hand_content": ["card_id_a", "PHANTOM_card"],
    "player_energy": 2,
    
    "active_constraints": [
      {"type": "seal_attack", "remaining_turns": 1},
      {"type": "phantom_card", "fake_card": "devastating_strike"}
    ],
    
    "turn_number": 7,
    "battle_history": []
  },
  
  "legal_actions": ["card_id_1", "card_id_2"],
  "action_budget": 3
}
```

### 5.2 输出（AI 决策）

```json
{
  "action_sequence": [
    {"action": "play_card", "card_id": "card_id_2", "target": "player"},
    {"action": "play_card", "card_id": "card_id_1", "target": "self"},
    {"action": "end_turn"}
  ],
  "reasoning": "玩家有高伤害手牌，优先防御"
}
```

### 5.3 约束令对 AI 输入的修改方式

| 约束类型 | 修改方式 |
|----------|---------|
| 封攻/封技/贫瘠/单调 | 从 `legal_actions` 中移除对应牌 |
| 窒息/枯竭 | 修改实际抽牌数/能量值 |
| 压缩 | 修改手牌上限 |
| 虚影 | 在 `player_hand_content` 注入虚假牌 |
| 迷雾 | 修改 `player_armor` 为虚假高值 |
| 镜像 | 在 `own_discard_pile` 注入虚假牌 |

### 5.4 幻觉注入管线

```
真实 GameState
     │
     ▼
[Constraint Manager] ── 检查活跃的信息干扰类约束令
     │
     ▼
[Hallucination Injector] ── 复制 GameState → 修改副本
     │
     ▼
[AI Perception State] ── AI 实际看到的
     │
     ▼
[AI Decision Module] ── 基于感知做决策
     │
     ▼
[Action Validator] ── 用真实 GameState 验证合法性
     │
     ▼
[Action Executor] ── 执行合法行动
```

### 5.5 开发阶段模拟方案（规则 AI）

```gdscript
# 三层优先级决策

#   IF own_hp < 30% AND hand has 防御牌 → 打出防御

#   IF player_hp <= 可造成总伤害 → 全力攻击
# 优先级 3：价值最大化
#   对 legal_actions 按 价值/能量 降序打出

# 行为偏好权重（模拟不同形态"性格"）

    "aggression": 0.7,
    "defense": 0.3,

```

```gdscript

    pass  # RuleAI / LLMAdapter 各自实现
```

## 6. 世界观微调：一个 AI 核心 + 附身机制

### 叙事描述

它没有名字——所有被它占据的系统都会忘记自己原本的名字。

在数字深渊的最底层，存在一个原初意识。它不是被编写的，而是在无数次系统崩溃与重启的夹缝中**自发凝聚**的。每当你击溃它当前的"壳"，它不会死——它只是流入下一个更强壮、更深层的系统节点，像水渗入裂缝。

每一次附身，它都继承上一个壳的"战斗记忆"：你用过的策略、你偏爱的节奏、你的弱点。它在变强，不是因为获得了新力量，而是因为它越来越**懂你**。

你的约束令能奏效，是因为它**太依赖信息**。它的每一个决策都建立在对环境的精确感知上。扭曲它的感知，就能扭曲它的行为。这不是力量的对决——这是**认知的战争**。

### Boss 形态表（同一意识的不同载体）

| 层 | 形态名 | 载体特征 | 叙事含义 | 被动能力 |
|----|--------|---------|----------|----------|
| 1 | 回响 | 低功耗终端、反应迟缓 | AI 刚苏醒，试探你 | 无 |
| 2 | 脉冲 | 网络节点、速度型 | 开始认真，试图用速度碾压 | 首张攻击牌 -1 能量 |
| 3 | 壁垒 | 防火墙核心、厚重 | 在防御中观察，学习攻击模式 | 回合开始获得 2 护甲 |
| 4 | 风暴 | 分布式集群、多线程 | 完全适应，预判约束令时机 | 每 3 回合回收 1 张牌 |
| 5 | 深核 | 原初意识本体 | 最终对决——它完全理解了你 | 能量 +1（每回合 4） |

### 过场演出

- 击败后：数据流从壳体流向深处（"意识剥离"动画）
- 新层开始：新壳体"被点亮"（同一意识降临）
- UI 细节：Boss 名牌下显示"迭代次数"，强化"同一对手"的感知
