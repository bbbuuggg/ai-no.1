## 5. 第一战预期流程（验证用）

### 预期回合线（8-10回合）

```
回合1: 双方试探（脉冲 vs 脉冲）
回合2: Boss打出蓄力协议 → 玩家注意到预警信号
回合3: ★决策点★ 玩家用行为锁定封蓄能释放 → 教学成功
回合4-6: 正常交换，Boss用自我修复 → 玩家学会下次封回复
回合7-8: Boss打出回响共鸣 → 玩家用协议否决取消
回合8-10: 收尾击败Boss（玩家HP剩余约55-60%）
```

### 数值验证

| 指标 | 目标 | 估算 |
|------|------|------|
| 战斗时长 | 8-10回合 | ~9回合 |
| 玩家剩余HP | 50-70% | ~58%（35/60 HP） |
| 约束令使用次数 | 2-3次 | 2.5次 |
| 玩家出牌/回合 | 3-4张 | 3.5张 |
| Boss出牌/回合 | 2-3张 | 2.5张 |
