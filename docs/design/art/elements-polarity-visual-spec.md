### 1.2 光暗描边光环（v1.1 静态、不动效）

| 极性 | 颜色 | 描边宽度 | 处理 |
|---|---|---|---|
| ☀️ **光 LIGHT** | `#F0D070`（金）| 4px | 外层 4px + 内层 1px 白 30% alpha 提亮 |
| 🌑 **暗 DARK** | `#3A1A4A`（紫黑）| 4px | 外层 4px + 内层 1px 黑 40% alpha 阴影 |
| **NONE（旧牌）** | 现有 accent 色 | 2px | 不变（兼容旧 reward）|

```gdscript
# BaseCardUI._draw() 文字层之前
match card_data.polarity:
    CardData.Polarity.LIGHT:
        draw_rect(Rect2(0, 0, CARD_WIDTH, CARD_HEIGHT), Color("F0D070"), false, 4.0)
        draw_rect(Rect2(4, 4, CARD_WIDTH-8, CARD_HEIGHT-8), Color(1, 1, 1, 0.3), false, 1.0)
    CardData.Polarity.DARK:
        draw_rect(Rect2(0, 0, CARD_WIDTH, CARD_HEIGHT), Color("3A1A4A"), false, 4.0)
        draw_rect(Rect2(4, 4, CARD_WIDTH-8, CARD_HEIGHT-8), Color(0, 0, 0, 0.4), false, 1.0)
```

### 1.3 文字颜色（v1.1 新增——不透明铺底导致必改）

**原则**：所有文字层在不透明元素色上必须 **WCAG AA 对比度 ≥ 4.5:1**。

| 底色 | 卡名（粗 20px）| 描述（细 14px）| 数值（粗 24px）|
|---|---|---|---|
| 🔥 火 `#E84A2A` | **白 `#FFFFFF`** + 1px 黑描边 | 白 `#FFF0E8` | 白 + 1px 黑描边 |
| 💧 水 `#3A8FE0` | **白 `#FFFFFF`** + 1px 黑描边 | 白 `#E8F0FF` | 白 + 1px 黑描边 |
| 🌿 木 `#4FB050` | **白 `#FFFFFF`** + 1px 黑描边 | 白 `#F0FFE8` | 白 + 1px 黑描边 |
| ⚪ NONE | **黑 `#222222`**（旧路径不变）| 灰 `#444` | 黑 `#222` |

**统一策略**：火/水/木 三色底全部用「**白字 + 1px 黑描边**」——一套 `Label` 样式覆盖三元素，不需要写 3 套。
**Godot 实现**：`LabelSettings.outline_color = Color.BLACK`、`outline_size = 1`，或用 `_draw_string` 时先 draw 黑字偏移 1px 再 draw 白字。

### 1.4 6 组合辨识度（v1.1 不透明强化）

不透明铺底后辨识度**全部升级**——之前担心的"水/暗蓝紫同色系"混淆问题被显著削弱（蓝底纯色 vs 紫黑边对比剧烈）。

| 组合 | 辨识度 | 备注 |
|---|---|---|
| 火/光（红底金边）| ⭐⭐⭐⭐⭐ | 强暖+强暖，最醒目 |
| 火/暗（红底紫边）| ⭐⭐⭐⭐⭐ | 强暖+强冷，对比剧烈 |
| 水/光（蓝底金边）| ⭐⭐⭐⭐⭐ | 冷暖正交 |
| 水/暗（蓝底紫边）| ⭐⭐⭐⭐ | 同冷色系但纯度差异大，**通过！** |
| 木/光（绿底金边）| ⭐⭐⭐⭐⭐ | 冷暖+饱和差异 |
| 木/暗（绿底紫边）| ⭐⭐⭐⭐⭐ | 互补色 |

**结论**：v1.0 担心的水/暗、火/暗混淆问题在不透明方案下**已自动解决**，不需要再加深紫黑。

## 2. 卡面绘制规格（v1.1）

### 2.1 元素图腾（中心水印，v1.1 唯一水印）

**位置**：cy = `CARD_HEIGHT * 0.55`（避开顶部条与卡名）
**尺寸**：直径 ~60px
**颜色**：与卡面元素色**对应深一档**的同色（增强层次）+ alpha 0.40

| 元素 | 图腾 | 几何 | 水印色 |
|---|---|---|---|
| 🔥 火 | 三角火焰 | 3 条 `draw_polyline` 外焰 + 内三角 | `Color("8A1F0A", 0.4)`（深红）|
| 💧 水 | 水滴 | 上半圆 `draw_arc` + 下 V 形两线 | `Color("0E3A6A", 0.4)`（深蓝）|
| 🌿 木 | 双叶 | 中茎直线 + 两侧椭圆叶轮廓 | `Color("1A4520", 0.4)`（深绿）|

**关键变化（v1.1）**：水印色从"白色 40%"改为"**同色深一档 40%**"——白底变彩底后，白水印会刺眼，深色水印才能保持优雅。

### 2.2 顶部标记条（v1.1 改造）

```
┌──────────────────────────────┐
│ ◆2  火  │  ☀ 光             │  ← 顶部条 28px，黑底半透明 60% alpha
│ ────────────────────────────│
│        (元素图腾水印)         │
│                              │
│           业火               │  ← 卡名（白字+黑描边）
│      造成 9 点伤害           │
└──────────────────────────────┘
```

**v1.1 关键调整**：
- 顶部条加 **黑底 60% alpha**（`Color(0, 0, 0, 0.6)`）—— 让能耗/元素/光暗文字在彩色卡面上有统一的可读区
- 不再用现有 accent 色作顶部条——彩底+accent 对比度不足
- **左 33%**：能耗 `◆N` + 元素汉字（火/水/木）
- **中 33%**：1px 白色分隔线
- **右 33%**：光暗符号 ☀/🌑 + 汉字（光/暗）

### 2.3 光暗符号几何

| 符号 | 几何 | 颜色 |
|---|---|---|
| ☀ 八芒星 | 8 条等长辐射线，长 8px，从中心 (rx, 14) 向外 | 金 `#F0D070` |
| 🌑 月牙 | 外圆 r=10 + 内圆 r=10 偏移 4px（差集形成月牙）| 紫白 `#C0A0E0`（在黑底条上要可读，**不**用紫黑）|

### 2.4 老 type 图腾（v1.1 决策：去掉）

**完全移除**剑/齿轮/闪电中心水印。理由：
- 决策 Q3 选 A2 「卡面清爽」
- type 字段仍在数据层使用（陷阱触发、LLM perception），但**视觉层不再呈现**
- ATK/DEF/SKL 的角色提示**改靠卡名 + 数值高低**自然传达（业火 9 点 = 攻击型一目了然）

## 3. BP 阶段卡背（v1.1：全露）

### 3.1 决策：**全露元素 + 光暗**

```
┌──────────────────────────────┐
│         ☀ 光                 │  ← 顶部条带光暗符号
├──────────────────────────────┤
│                              │
│          🔥                  │  ← 元素图腾大图（占卡面 50%）
│                              │
│         ?  ?  ?              │  ← 卡名/能耗/数值仍隐藏
│                              │
│      (金色/紫黑描边)         │  ← 完整光暗描边光环
└──────────────────────────────┘
```

**实现**：
- 卡背完全用 `_draw()` 重绘（**不再使用 `card_back.png`**）
- 元素色不透明铺底 100%
- 顶部条只显示光暗符号（无能耗、无卡名）
- 中心大元素图腾（直径 ~80px，alpha 0.55，比正面 0.4 更显眼）
- 光暗描边光环正常显示

**新手友好性 + 战术影响**：
- ✅ 玩家所见即所得：BP 阶段就能数对手 4 张里"几火几水几木 + 几光几暗"
- ⚠️ **2:2 平衡 ×2.0 的悬念归零** —— 对手凑齐 2:2 时玩家可以提前看到，可能反向利用（"对方光暗都凑齐，我马上换防御牌"）
- 📋 **后续观察项**：Sprint B 烟雾测试 3 局后，如果发现"全露让博弈过浅"，再切回半露（Q2 → A1）

### 3.2 LLM-Boss 接口影响

`perception_builder.gd` 在未来构造对手感知时**可以直接读 element + polarity 字段**——不需要"猜对手底牌"的推理逻辑。这简化 ADR-001 的 LLM prompt 工程，但也意味着 LLM 的"读心术"价值变小。**Sprint B 时重新评估 LLM 推理深度**。
