## 1. 诊断：当前"暗出对决"为什么对决感薄？

从三个维度看**对决感的来源**：

| 维度 | 当前实现 | 问题 |
|------|---------|------|
| **决策点数量** | 1 个：暗出阶段一次性选好 N 张牌+排序 | 整个回合就一次决策，做完只能等结果 |
| **反应空间** | 0 个：双方暗出后立即翻开，无反应窗口 | 没有"我看你这一手 → 我换我那一手"的来回 |
| **信息流动** | 阶梯式：部署阶段（看 Boss 手牌类型）→ 暗出（双方独立做决策）→ 翻开（一次性）| 信息流动是 1 步阶梯，不是 5 步阶梯 |

**对照 LoL BP**：
- 决策点：5 个 Pick + 多个 Ban，每一步都是独立选择
- 反应空间：每一步都看到对方上一步选了什么，可以针对性反应
- 信息流动：边选边暴露，节奏感强

**结论**：当前机制更像**石头剪刀布**（双方同时出，一次决胜负），而非**对弈**（轮流落子，逐步暴露意图）。陷阱系统和认知探针**部分**弥补了这个问题（陷阱 = 玩家先动+预设伏击，探针 = Boss 先动+预判），但**核心碰撞阶段仍然是同步的**。

## 2. 三个候选方案

### 方案 A：完全 BP 式（明牌轮流）⭐⭐ 改造最大

**一句话定位**：双方亮着牌打——把博弈完全推到明牌的"先后手 + 时序选择"上。

**完整时序**：
```
┌──────────────────────────────────────────────────────────┐
│ 1. 回合开始（双方抽牌+回能）                                │
│    *新增*：随机或固定决定本回合先手方                       │
└──────────────────────────┬───────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────┐
│ 2. 部署阶段（同现行：陷阱+干扰探针）                        │
└──────────────────────────┬───────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────┐
│ 3. BP 阶段（明牌轮流出牌）★ 新                              │
│   先手方选 1 张牌正面摆出 → 后手方看到后选 1 张正面摆出      │
│   → 先手方选第 2 张 → 后手方选第 2 张 → ...                │
│   每轮可选 "Pass"（不出，结束自己的 BP）                    │
│   双方都 Pass / 任一方能量耗尽 → BP 结束                    │
└──────────────────────────┬───────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────┐
│ 4. 结算阶段                                                │
│   按出牌时序逐对碰撞结算（玩家第 N 张 vs Boss 第 N 张）    │
│   多余牌 100% 直接生效                                     │
│   陷阱在 Boss 牌出场即时触发                                │
└──────────────────────────┬───────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────┐
│ 5. 认知结算（同现行）+ 6. 回合结束                          │
└──────────────────────────────────────────────────────────┘
```

**信息可见度**：

| 信息 | 玩家可见 | Boss 可见 |
|------|---------|----------|
| 对方已出的牌（牌名+数值+顺序）| ✅ 完全 | ✅ 完全 |
| 对方手牌内容 | ❌ | ❌ |
| 对方手牌类型分布 | ✅（沿用 BossBlindLane）| ✅ |

**与现有系统兼容性**：

| 系统 | 影响 |
|------|------|
| 三角克制 | ✅ 保留 |
| 陷阱系统 | ✅ 保留，但触发时机变为"Boss 在 BP 中明牌打出时" → 大幅减弱（玩家能看到 Boss 出什么再决定不触发吗？答案：不行，陷阱在部署阶段就锁定了，Boss 仍可能踩） |
| 认知探针 | ⚠️ 削弱：Boss 已经看到玩家所有牌，"猜测"无意义 → 改为"行为模式分析"或干脆移除 |
| 0 费绑定 | ✅ 保留，但需重新设计 UI（在已出牌右侧拖拽叠加） |
| LLM Boss | ⚠️ 行为模型彻底重写（从"一次性暗出决策"变为"逐 turn 反应决策"，token 成本至少翻 2-3 倍） |

**优劣分析**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 博弈深度 | ⭐⭐⭐⭐⭐ | 决策点 1 → 5+，反应空间从无到有 |
| 学习成本 | ⭐⭐ | 玩家需理解"先手优劣"、"何时 Pass"、"压牌还是抢节奏" |
| 实现成本 | ⭐⭐⭐⭐⭐（高代价）| 状态机重写 + LLM 重设计 + UI 大改（约 2-3 周） |
| 视觉演出潜力 | ⭐⭐⭐⭐⭐ | 看着双方一步步落牌 = 真实对弈观感 |
| 与设计支柱契合 | ⭐⭐ | 与 Pillar 2"不对称对决"冲突——双方变得太对称（都是明牌打牌）|

**致命副作用**：**心理战美学的丢失**。GDD-04 设计哲学第一句"核心体验从'计算最优出牌'变为'预判对手 + 被对手预判'"——明牌之后没有预判，只有计算。

### 方案 B：半暗 BP（轮流暗放，类型公开）⭐⭐⭐ 推荐

**一句话定位**：每张牌轮流"暗放"，但**类型立刻公开（攻/防/技/协）**，**具体牌名 + 数值在结算时才翻开**。

**完整时序**：
```
┌──────────────────────────────────────────────────────────┐
│ 1. 回合开始 + 2. 部署阶段（同现行）                         │
└──────────────────────────┬───────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────┐
│ 3. BP 阶段（轮流暗放，类型公开）★ 新                        │
│   玩家先放 1 张：选择手牌中一张面朝下放到台面 #1 位          │
│       → 系统立即广播"玩家放了一张 [攻击]"（类型公开）        │
│   Boss 反应：选择并放下自己的 #1（类型公开）                 │
│   玩家放 #2 → Boss 放 #2 → ...                            │
│   任一方主动 Pass / 能量耗尽 → BP 结束                     │
│   *关键*：放下后不可撤回（承诺机制）                         │
└──────────────────────────┬───────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────┐
│ 4. 翻牌结算阶段                                            │
│   双方逐对翻开（#1 ↔ #1，#2 ↔ #2，...）                   │
│   每对翻开有 1.5s 演出窗口（看到具体牌名+数值+克制结果）    │
│   多余牌 100% 直接生效 + 陷阱在 Boss 翻开时触发              │
└──────────────────────────┬───────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────┐
│ 5. 认知结算（同现行）+ 6. 回合结束                          │
└──────────────────────────────────────────────────────────┘
```

**核心张力**：
- **类型公开**让你能"看到 Boss 第 1 张是攻击 → 我第 2 张换成技能（克制）"
- **牌名暗藏**让你**不知道 Boss 那张攻击是 5 伤还是 12 伤**——预判仍存在
- **轮流承诺**让先手方承担"被针对"风险，后手方享受"针对"收益（与 LoL 一致）

**信息可见度**：

| 信息 | 玩家可见 | Boss 可见 |
|------|---------|----------|
| 对方已放牌的**类型** | ✅ 立即 | ✅ 立即 |
| 对方已放牌的**牌名+数值** | ❌（结算时才翻）| ❌（结算时才翻）|
| 对方已放牌的**位置/张数** | ✅ | ✅ |
| 对方手牌类型分布 | ✅ | ✅ |
| 对方手牌内容 | ❌ | ❌ |

**与现有系统兼容性**：

| 系统 | 影响 |
|------|------|
| 三角克制 | ✅ 完全保留，且**博弈中心**：每次放牌都是选择"克制 / 被克制 / 同型"的赌博 |
| 陷阱系统 | ✅ 完全保留，且**升级**：玩家看到"Boss 放了攻击" → 部署阶段没开攻槽就慌了（戏剧张力） |
| 认知探针 | ✅ 保留：仍然是 Boss 猜玩家"主导类型"，但因为类型已公开，改为"猜玩家**第 N 张**的类型"（更难） |
| 0 费绑定 | ✅ 保留，绑定时类型不变（攻牌+0费攻仍是攻），所以不破坏类型公开规则 |
| LLM Boss | ⚠️ 中等改造：增加"看到玩家上一张类型 → 选择本次类型"的反应函数。可以做成**确定性反应规则 + LLM 偶尔介入**（保 token 成本）|

**优劣分析**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 博弈深度 | ⭐⭐⭐⭐ | 决策点 1 → 3-5，反应空间存在但仍有暗藏 |
| 学习成本 | ⭐⭐⭐⭐ | "类型公开+牌名暗"很直观（你看到红/蓝/绿色的卡背就够了），1 局学会 |
| 实现成本 | ⭐⭐⭐ | 状态机改写但范围可控（约 1-1.5 周）；UI 主要加"放牌台面"区域 |
| 视觉演出潜力 | ⭐⭐⭐⭐⭐ | 类型彩色卡背 + 翻牌时刻的反转感（"原来是 12 伤的过载冲击！"）|
| 与设计支柱契合 | ⭐⭐⭐⭐ | Pillar 1（克制攻势）+ Pillar 2（不对称——LLM 仍藏在牌后）+ Pillar 4（可读复杂度，类型颜色一眼看懂）|

**关键创新**：**双层信息**——类型层公开（决策依据）/ 数值层暗藏（不确定性）。这是对当前"全暗 + 一次性翻"和"全明 + 全程公开"的**第三条路**。

### 方案 C：Ban + 暗 Pick 混合 ⭐ 改造最小

**一句话定位**：保留现有暗出对决核心，**只在前面加一个"Ban 阶段"**——双方互禁一张对方手牌。

**完整时序**：
```
┌──────────────────────────────────────────────────────────┐
│ 1. 回合开始（同现行）                                       │
└──────────────────────────┬───────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────┐
│ 2. *新增* Ban 阶段                                         │
│   玩家先 Ban：从 Boss 手牌的 4 张中选 1 张 [类型] 标记禁用   │
│        （只能看到类型，看不到具体牌名）                      │
│   Boss 后 Ban：同样从玩家手牌中选 1 张类型标记禁用            │
│   被 Ban 的牌本回合不可出（保留在手牌、不消耗能量）           │
└──────────────────────────┬───────────────────────────────┘
                           ▼
┌──────────────────────────────────────────────────────────┐
│ 3. 部署阶段（同现行）+ 4. 暗出阶段（同现行）+ 5. 对决（同现行）│
└──────────────────────────┬───────────────────────────────┘
                           ▼
┌─ 6. 认知结算 + 7. 回合结束 ─┐
└──────────────────────────┘
```

**信息可见度**：与当前几乎一致，只多了"双方知道对方一张牌的类型被禁了"。

**与现有系统兼容性**：

| 系统 | 影响 |
|------|------|
| 三角克制 / 陷阱 / 认知探针 / 0 费 | ✅ 全部不动 |
| LLM Boss | ⚠️ 新增 Ban 决策函数（小成本） |
| 后续逻辑 | ✅ 暗出/碰撞/结算流程完全不变 |

**优劣分析**：

| 维度 | 评分 | 说明 |
|------|------|------|
| 博弈深度 | ⭐⭐⭐ | 决策点 1 → 2，仅前置增加一个 Ban 选择 |
| 学习成本 | ⭐⭐⭐⭐⭐ | 老玩家几乎无感，新玩家容易理解 |
| 实现成本 | ⭐⭐ | 1-3 天工作量 |
| 视觉演出潜力 | ⭐⭐ | 仅 Ban 阶段的提示动画，无戏剧弧 |
| 与设计支柱契合 | ⭐⭐⭐ | 不破坏现有支柱，但也没显著强化对决感 |

**风险**：用户可能觉得"还是石头剪刀布，只是多了个手前预热"。**这个方案治标不治本**。

## 4. vibe-lead 推荐

### 推荐 → **方案 B：半暗 BP**

**三个理由**：

1. **博弈含金量提升的根本来源是"决策点数量+反应空间"**，方案 B 同时拿到这两个（决策从 1 到 3-5，反应空间在类型层完全开放）；方案 C 只动了前面，方案 A 走得太远以致破坏了 Pillar 2。

2. **保留了核心美学**：GDD-04 开篇说"心理战美学" = "预判对手 + 被对手预判"。方案 B 把心理战从**完全暗箱猜测**升级为**类型确定+数值不确定的概率推理**——这才是更高维度的心理战。

3. **戏剧张力实际更强**：方案 A 因为全明牌，反转的爽感被消解（你早就知道对方有什么）；方案 B 在翻牌时刻能产生**"我以为你是 5 伤的小攻击，没想到是 12 伤的过载冲击！"**的反转——这是单机卡牌游戏的高光时刻。

### 实施路线（如选 B）

| 阶段 | 工作量 | 内容 |
|------|--------|------|
| Sprint A（3-5 天）| 中 | GDD-04 重写 + 状态机 BP 阶段 + UI 台面区域 |
| Sprint B（3-5 天）| 中 | LLM Boss 反应函数 + 平衡测试 |
| Sprint C（2 天）| 小 | 翻牌演出 + 认知探针适配 + 平衡数值 |
| **合计** | **8-12 天** | 不破坏 v0.5.0/0.5.1 已有产出 |

## 6. 风险与回退方案
